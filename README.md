# robocomp

[Bevy][bevy-web] Plugin for Robot/Rigid-Body composition using [URDF][urdf-wiki] inspired physics agnostic components.

For use with editors like [Blender][blender-web] (via [Skein][skein-github]) etc.

[bevy-web]: https://bevy.org/
[urdf-wiki]: https://en.wikipedia.org/wiki/URDF
[skein-github]: https://github.com/rust-adventure/skein
[blender-web]: https://www.blender.org/
